# FlipCoin

A coin flip app with the production value of a AAA game trailer. Animated gradients, particle effects, haptic choreography — all for a 50/50 random outcome. Sometimes overkill is the point.

## Features

- **Physics-based flip animation** with realistic 3D rotation
- **Animated gradient backgrounds** that shift with each flip
- **Particle effects** on landing — because confetti makes everything better
- **Haptic choreography** — tactile feedback synced to the animation
- **Flip history** with heads/tails statistics
- **Custom coins** — change faces, colors, and weight bias
- **Shake to flip** using accelerometer

## Tech Stack

- SwiftUI
- Core Animation + Metal hints
- Core Haptics
- Core Motion (accelerometer)
- Combine

## Getting Started

```bash
git clone https://github.com/sebastiandoyle/flipcoin-app.git
cd flipcoin-app
open *.xcodeproj
```

Requires Xcode 15+ and iOS 17+.
